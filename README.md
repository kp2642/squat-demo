# 스쿼트 코치 데모

AI 운동 코치 앱의 1~2주차 검증용 웹 데모입니다. 휴대폰 카메라로 옆모습을 인식해 스쿼트 횟수를 세고, 자세를 음성으로 교정합니다.

- 주소: https://kp2642.github.io/squat-demo/
- 자세 인식: MediaPipe Pose (브라우저 안에서 처리, 영상은 기기 밖으로 나가지 않음)
- 판정 기준: 편하게(입문) / 정확하게 중 선택
- 기준 미달 반복은 세지 않음(v6): 주저앉기, 깊이 기준보다 15° 넘게 덜 앉음, 정확하게 모드에서 상체를 많이 숙임
- 세트가 끝나면 반복마다 판정이 맞았는지 기록해 정확도를 확인할 수 있음

통증이 느껴지면 즉시 멈추세요. 의료·재활 목적이 아닙니다.

## 끊김 줄이기·초보 난이도 (v13)
- 운동 중 잠깐 안 보여도 3초(스쿼트 2.5초)까지는 이어서 추적, 흐릿한 관절도 운동 중엔 받아들임, 엎드림 오인식은 1.5초 넘게 이어질 때만 쉬는 것으로 봄. 다시 시작하면 "이어서 하세요"
- 푸시업 자세: 의자 짚고(처음) / 무릎 대고(입문, 기본값) / 기본
- 편하게: 팔꿈치 110°까지 인정, 솟음 허용 25°. 깊이로 안 세는 기준은 120°(정확하게 110°)

## 푸시업 1차 실측 반영 (v12)
- 허리 처짐 안 셈 기준: 허용치+10° → +5°(편하게 20° 초과)
- 팔꿈치 40° 미만(바닥까지 내려앉음)은 안 셈

## 초광각 선택 수정 (v11)
- 초광각을 골랐는데 앞면 카메라가 나오던 문제: 앞면은 후보에서 빼고, 열린 카메라가 앞면이면 일반 뒷면으로 다시 엶. 결과 복사에 카메라 이름·목록 기록

## 자리 잡기 음성 안내 (v10)
- 시작 전 "조금 더 가까이 / 멀리", "어깨·발목이 잘려요", "화면 가운데로" 등을 음성으로 안내하고, 자리가 맞으면 "좋아요, 그 자리예요"

## 카메라 가까이 (v9)
- 스쿼트도 어깨~발목만 화면에 들어오면 판정(머리·발끝은 잘려도 됨) → 세로 약 1.5m, 초광각 약 1m

## 가로 모드·초광각 (v8)
- 휴대폰을 가로로 두거나 회전 잠금 상태여도 몸 방향을 보고 90° 단위로 자동 보정
- 카메라: 앞면 / 뒷면 / 뒷면 초광각(기기 목록에서 이름으로 찾음, 없으면 일반 뒷면)
- 화면은 잘리지 않게 전체 프레임을 보여줌

## 푸시업 (v7)
- 종목에서 푸시업 선택, 기본 / 무릎 대고(입문)
- 휴대폰을 바닥에 세워 2.5~3m 옆에서 촬영, 팔을 편 엎드린 자세로 1초 멈추면 시작
- 판정: 팔꿈치 각도(편하게 100° / 정확하게 90°), 엉덩이 처짐(15° / 10°), 엉덩이 솟음(20° / 15°), 빠른 하강(0.6초)
- 안 셈: 허리 처짐이 허용치보다 10° 넘음(모드 무관), 깊이 기준보다 20° 넘게 덜 내려감, 정확하게 모드에서 몸통 선이 허용치보다 5° 이상 벗어남
